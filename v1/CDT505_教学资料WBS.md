# CDT505 教学资料WBS

2026-11-01。教学资料按知识主题组织，每个专题包含讲解、练习与速查。医院建设提供贯穿背景；每节重新交代当前工作和所用条件。

## 编排原则

先介绍当前问题，再给标准中英文术语与解释，随后示范计算、作图或判断。练习提供局部所需条件；速查保留定义、公式、适用条件和例子。篇幅较短且属于同一过程的内容合并，不以专题数量作为完成标准。

需求与WBS合并后，阅读顺序为需求、范围边界、WBS、100%规则、工作包词典、范围基线、活动表。读者先认识基线的组成，再理解基线。风险识别、评估、应对与复查按同一过程连续讲解。单项目资源和多项目共享资源也放在同一专题比较。

全课10个主题、23个专题。主题1至8的17个专题已经制作，包含101节讲解、194道选择题、32组可核对的分项练习、66道案例或解释题、101条速查。另有26节配有可修改参数或图表的工作区；AON作图、正推逆推、PERT与依赖关系练习继续保留。浏览页面不计作掌握，开放题提供参考与判断依据。

学习页采用一条阅读顺序：背景和术语、例子、概念判断、计算或作图、应用。上一版叠加的案例卡已撤下；完整案例推导保存在案例册与练习页的回看入口。35组独立案例集中在专题“练习”页。速查从本节正式定义、公式和表格生成，不再附加整套教学推导。查看解法与独立答对分别记录。对照记录见[样板对照与课件核对](CDT505_样板对照与课件核对.md)。

## 每个专题的制作工作包

| 工作包 | 完成条件 |
|---|---|
| 内容与先修 | 重要术语先定义；当前问题、用途和所需背景明确 |
| 例子与推导 | 对象、名称、条件一致；计算与图形能逐步说明 |
| 判断与应用 | 错误选项对应实际误解；案例题提供依据和取舍 |
| 操作工作区 | 当前参数与结果对应；非法输入不会保留旧结论 |
| 速查与检索 | 定义、公式条件、例子能直接找到；不用回原PDF补解释 |
| 阅读与行为检查 | 检查顺序、全文措辞、就近资料、窄屏、保存与恢复 |
